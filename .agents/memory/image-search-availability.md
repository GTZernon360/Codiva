---
name: Busca de imagens
description: Limitação observada ao tentar obter uma imagem pública durante este projeto.
---

O callback de busca de imagens pode não estar disponível no modo atual do workspace e solicitar confirmação de modo pago.

**Why:** Um recurso visual essencial não deve depender de uma ferramenta que pode estar indisponível para a sessão.

**How to apply:** Para imagens não essenciais, use uma fonte pública existente; para imagens essenciais, prefira um asset local ou uma ilustração SVG simples quando a busca não estiver disponível.
